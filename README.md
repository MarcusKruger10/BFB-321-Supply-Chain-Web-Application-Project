# BFB-321-Supply-Chain-Web-Application-Project

## Running the app
run this preview command in the repo: python ..\BFB-preview\preview.py
Once the local preview server is running, open [http://127.0.0.1:8000/](http://127.0.0.1:8000/). The app opens on the Log In page.

The username and password fields are pre-filled with the demo credentials: username `BFB321` and password `BFB321`. Click **Log in** to reach the Dashboard. This is a demo-only login and is not real authentication.
